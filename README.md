# Математика — сабақ материалдары

Сайт учителя математики: учитель загружает материалы, ученики открывают их по **коду класса**
(без регистрации). Интерфейс на казахском языке, мобильная версия в первую очередь.

- **Ученик**: `/`: вводит код (например, `KUN47`) один раз или сканирует QR. Видит только материалы своего класса и общие («Барлық сыныптар»).
- **Учитель**: `/admin`: вход по PIN, классы (коды, QR-карточки для печати), материалы (файлы, ссылки, YouTube).

Зависимости: только `pg` (Postgres) и `qrcode`. Сервер: Node.js без фреймворков. Шрифт Nunito встроен в сайт, поэтому работает и без интернета.

## 1. Запуск на Render + Neon (пошагово)

### Шаг 1. Код на GitHub
1. Создайте на github.com новый **приватный** репозиторий, например `matematika`.
2. Загрузите в него содержимое этой папки (кроме `node_modules/` и `data/`, они уже в `.gitignore`):
   ```bash
   git init
   ```
   ```bash
   git add . && git commit -m "Математика сайты"
   ```
   ```bash
   git branch -M main
   ```
   ```bash
   git remote add origin https://github.com/<ваш-логин>/matematika.git
   ```
   ```bash
   git push -u origin main
   ```

### Шаг 2. База данных Neon
1. Зайдите на **neon.tech** → *Sign up* (можно через Google/GitHub).
2. *Create project*: имя `matematika`, Postgres 16 или новее, регион **AWS Europe (Frankfurt)**, ближайший к Казахстану.
3. На странице проекта нажмите **Connect** и скопируйте строку подключения. Она выглядит так:
   `postgresql://neondb_owner:ПАРОЛЬ@ep-xxxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`
   Это ваш `DATABASE_URL`. Никому его не показывайте.
4. Таблицы создавать не нужно: сайт создаст их сам при первом запуске.

> Узнайте лимит хранилища на бесплатном тарифе Neon (*Billing*). Если он **0,5 ГБ**, добавьте на шаге 3
> переменную `STORAGE_LIMIT_MB=500`, чтобы счётчик «МБ из …» показывал правильный предел.

### Шаг 3. Веб-сервис на Render
1. Зайдите на **render.com** → *Sign up with GitHub*.
2. **New → Web Service** → выберите репозиторий `matematika`.
3. Настройки:
   | Поле | Значение |
   |---|---|
   | Language | Node |
   | Region | Frankfurt (EU Central) |
   | Build Command | `npm install --omit=dev` |
   | Start Command | `npm start` |
   | Instance Type | **Free** |
4. В разделе **Environment Variables** добавьте:
   | Ключ | Значение |
   |---|---|
   | `DATABASE_URL` | строка из Neon (шаг 2) |
   | `ADMIN_PIN` | ваш PIN, например `482913` (лучше 6+ цифр) |
   | `NODE_VERSION` | `22` |
   | `SEED_DEMO` | `1`: только при первом запуске, если нужен пример |
5. *Create Web Service*. Через 2–3 минуты сайт откроется по адресу вида `https://matematika-xxxx.onrender.com`.

> Можно вместо шага 3 нажать **New → Blueprint**: Render прочитает файл `render.yaml` и сам заполнит настройки.
> Останется ввести `DATABASE_URL` и `ADMIN_PIN`.

### Шаг 4. Первый вход
1. Откройте `https://…onrender.com/admin` и введите PIN.
2. Если включали `SEED_DEMO=1`, увидите пример: классы 7Ә, 8Ғ, 9А и 5 материалов.
   После этого **удалите** переменную `SEED_DEMO` в Render (*Environment*). Повторно пример не добавится, но лишняя переменная не нужна.
3. Вкладка **Сыныптар** → «QR карточка» → «Басып шығару»: лист A4 с 8 карточками для класса.

### Особенности бесплатных тарифов
- **Render Free засыпает** через 15 минут без посетителей. Первое открытие после этого занимает 30–60 секунд, потом сайт работает быстро.
  Перед уроком откройте сайт заранее.
- **Neon** тоже «засыпает»; первый запрос после паузы на 1–2 секунды дольше.
- Файлы хранятся в базе Neon (тип `bytea`), поэтому на Render ничего не теряется при перезапуске.

## 2. Переход на Backblaze B2 (10 ГБ бесплатно)

1. **backblaze.com** → B2 Cloud Storage → *Create a Bucket*: имя, например `matematika-files`, тип **Private**.
2. *Application Keys* → *Add a New Application Key*: доступ только к этому bucket, *Read and Write*.
   Скопируйте **keyID** и **applicationKey** (ключ показывается один раз).
3. В Render → *Environment* добавьте:
   | Ключ | Значение |
   |---|---|
   | `B2_KEY_ID` | keyID |
   | `B2_KEY` | applicationKey |
   | `B2_BUCKET` | `matematika-files` |
4. Сохраните. Render перезапустит сайт, и при запуске **все файлы из базы автоматически перенесутся в B2**
   (в логах: `→ #1 «…» перенесён: db → b2`). Новые файлы сразу пойдут в B2, лимит на странице учителя станет 10 ГБ.

Подробности:
- Адрес B2 определяется автоматически по ключу. Если нужно задать его вручную: `B2_ENDPOINT=https://s3.us-west-004.backblazeb2.com`.
- Перенос безопасен: сначала файл копируется в B2, потом обновляется запись в базе, и только после этого удаляется старая копия.
  Если перенос прервётся, при следующем запуске он продолжится. Пока файл не перенесён, он скачивается из старого места.
- Ручной запуск переноса: `npm run migrate-files` (с теми же переменными окружения).
- Файлы всегда отдаются через сайт с проверкой класса, прямых ссылок на B2 у учеников нет.

## 3. Школьный компьютер без интернета

Нужен Node.js 20+ (nodejs.org). Интернет нужен один раз, для `npm install`.

```bash
npm install
```
```bash
npm start
```

- Без `DATABASE_URL` всё хранится в папке `data/` (`data/db.json` + `data/files/`). Для резервной копии достаточно скопировать эту папку.
- Без `ADMIN_PIN` страница учителя открывается **только с этого компьютера**: `http://localhost:3000/admin`.
  С других устройств она закрыта. Если задать `ADMIN_PIN`, вход по PIN будет работать с любого устройства.
- Ученики в той же Wi-Fi сети открывают `http://<IP-компьютера>:3000`. QR-карточки сами подставляют IP компьютера в школьной сети.
  Можно указать адрес явно: `PUBLIC_URL=http://192.168.1.10:3000`.
- Пример данных: `npm run seed`.

## 4. Переменные окружения

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | Postgres (Neon). Если не задана, используется папка `data/` |
| `ADMIN_PIN` | PIN учителя. **Если сайт в интернете и PIN не задан, страница учителя закрыта** |
| `B2_KEY_ID`, `B2_KEY`, `B2_BUCKET` | Включают хранение файлов в Backblaze B2 и перенос старых файлов |
| `B2_ENDPOINT` | Необязательно: S3-адрес B2 |
| `STORAGE` | Необязательно: принудительно `db`, `local` или `b2` |
| `STORAGE_LIMIT_MB` | Предел для счётчика места (по умолчанию 1024, для B2 10240) |
| `PUBLIC_URL` | Адрес сайта для QR, если определяется неверно |
| `SEED_DEMO=1` | Создать пример при первом запуске |
| `ANTHROPIC_API_KEY` | Включает AI-проверку фото домашних работ |
| `AI_MODEL`, `AI_EFFORT` | Модель (по умолчанию `claude-opus-5-5`) и глубина проверки (`medium`) |
| `CODE_MAX_FAILS` | Неверных кодов с одного IP за 15 минут до блокировки (по умолчанию 20) |
| `PIN_MAX_FAILS` | Неверных PIN с одного IP за 15 минут (по умолчанию 5) |

## 5. Ученики по именам и ответы с автопроверкой

**Список класса (по желанию).** Сыныптар → «👥 Оқушылар» → вставить ФИО по одному на строку (можно скопировать из Kundelik или Excel; нумерация «1.» убирается сама).
- Пока списка нет, класс открывается по одному коду, как раньше.
- Когда список есть, ученик после кода выбирает своё имя и при первом входе придумывает PIN из 4 цифр. Телефон запоминает вход на год.
- Каждое имя может занять только один ученик. Если ученик забыл PIN или имя занял кто-то другой, нажмите «🔑 PIN тастау»: старая сессия закончится, ученик придумает новый PIN.
- 5 неверных PIN подряд для одного имени — вход под этим именем закрыт на 15 минут.
- Список видят все, у кого есть код класса, поэтому можно писать кратко: «Әлия С.».

**Ключ ответов.** В форме материала блок «✏️ Жауап кілті»: одна строка — ответ к одной задаче.
- `3,5` = `3.5` = `7/2`, `x = 5` = `5`; корни через `;` в любом порядке (`2; -3`); несколько верных вариантов через `|` (`0,5 | 1/2`).
- Проверка на сервере, правильные ответы на телефон не передаются. Исправленный ключ пересчитывает уже сданные работы.
- «📊 Нәтижелер»: таблица ученик × задача, процент решивших каждую задачу, кто не сдал (для классов со списком), выгрузка в Excel (CSV).

**Фото домашней работы.** В форме материала блок «📷 Үй жұмысының фотосын қабылдау», при желании срок сдачи.
- Ученик нажимает «📷 Үй жұмысын жіберу» и прикладывает 1–6 фото (камера или галерея) и комментарий. Фото сжимаются на телефоне до ~150–400 КБ.
- Учитель: «📷 Жұмыстар» → фото по ученикам, просмотр на весь экран (← →, поворот), оценка и комментарий → «✅ Тексерілді». Ученик видит оценку на карточке.
- Фото видит только учитель и сам ученик (для классов без списка — только учитель). Отправка после срока помечается «кешігіп».
- Место: 30 учеников × 2 фото ≈ 15–25 МБ на одно задание. Счётчик показывает, сколько занимают фото; «🗑 Барлық фотоны жою» освобождает место. При нехватке — переход на Backblaze B2 (раздел 2), фото переносятся автоматически.

**🤖 AI-проверка фото (по желанию).** Включается переменной `ANTHROPIC_API_KEY` в Render (Environment).
1. Ключ: console.anthropic.com → Settings → API Keys → Create Key; пополните баланс (Billing). Ключ храните только в Render.
2. В «📷 Жұмыстар» появятся «🤖 AI тексеру» у работы и «🤖 Барлығын AI-мен тексеру».
3. ИИ (по умолчанию Claude Opus 5.5) смотрит фото, условие задания (если задание — PDF) и ключ ответов (если есть) и предлагает: ✅/❌/❓/➖ по каждой задаче с пояснением, оценку и комментарий ученику.
4. «Ұсынысты қою» подставляет оценку и комментарий в поля. **Ученик ничего не видит, пока учитель не нажмёт «✅ Тексерілді».**
- В поле «🤖 AI үшін нұсқау» у задания можно задать шкалу и критерии («10 баллдық жүйе», «№5 — қосымша»).
- В Anthropic уходят только фото, условие, ключ, указание учителя и комментарий ученика — без имени ученика. Предупредите школу/родителей, что фото тетрадей проверяются ИИ.
- Ориентировочно $0,03–0,10 за работу из 2 фото (зависит от числа задач). Дешевле: `AI_MODEL=claude-sonnet-5-5` или `claude-haiku-5-5` (хуже читают почерк). Глубже, но дороже: `AI_EFFORT=high`.

**📲 Приложение (PWA).** Сайт можно установить на телефон как приложение — без Google Play и App Store, бесплатно.
- Android (Chrome): плашка «Орнату» вверху страницы → «Установить». Иконка «Математика» появится на экране.
- iPhone (Safari): «Орнату» показывает подсказку: «Бөлісу» → «Экранға қосу» → «Қосу». На iPhone приложение хранит вход отдельно от Safari, поэтому код класса (и PIN) нужно ввести один раз заново.
- Без интернета приложение показывает экран «Интернет байланысы жоқ». Материалы, файлы, фото и ответы не сохраняются на телефоне — всегда идут через сервер с проверкой доступа.
- Обновления сайта приходят в приложение сами.
- **Без интернета:** у каждого файла кнопка «📥» (и «Барлығын сақтау» сверху) сохраняет PDF/Word/PowerPoint в телефон. Без сети приложение открывается со списком на момент последнего входа; сохранённые файлы открываются, видео/ссылки/ответы помечены «Интернет керек». При сети доступ к файлам по-прежнему проверяет сервер. При выходе из класса сохранённое удаляется. Работает только по https (на Render), на школьном http-адресе — нет.

**🎯 ЕНТ нұсқалары (тренировка).** Загрузите вариант в PDF → «✏️ Жауап кілті» → «🎯 ЕНТ нұсқасы»: предмет, время, буквы (A–E). Ключ — по строке на вопрос: `B` (один ответ, 1 балл) или `ACE` (несколько, 2 балла; одна ошибка — 1 балл).
- Ученик видит раздел «🎯 ЕНТ нұсқалары» сверху, нажимает «Бастау»: таймер, PDF с вопросами, бланк с кружками. Ответы и таймер сохраняются при перезагрузке; когда время вышло — бланк отправляется сам.
- Результат: баллы по каждому вопросу (✅ / 🟡 частично / ❌). В «📊 Нәтижелер» у учителя — таблица с ½ за частичные ответы.
- **Формат ЕНТ (по умолчанию): 40 вопросов, 50 баллов.** 1–25 — один ответ A–D (1 балл); 26–30 — контекстные, с общим текстом/рисунком (1 балл); 31–35 — сәйкестендіру «1 → ?, 2 → ?» (2 балла, одна пара — 1); 36–40 — несколько ответов A–F (2 балла, одна ошибка — 1). Ключ в поле: `B` / `B,D` / `ACE`. Есть «Еркін формат» для своих вариантов (любое число вопросов и букв).
- **Один вопрос на экране:** «📝 Сұрақтарды бөлек экранға енгізу» — у каждого вопроса скриншот (Ctrl+V / перетаскивание / выбор файла) и/или текст, варианты (необязательно) и галочки правильных ответов; ключ собирается сам. Ученик листает вопросы «← Алдыңғы / Келесі →», сверху сетка номеров. Без вопросов — режим PDF + бланк.
- **Дроби и степени:** в тексте пишите `3/4`, `(x+1)/(x-2)`, `x^2` — ученик видит дробь столбиком и степень; в редакторе есть предпросмотр.
- Пример: `seed/ЕНТ_үлгі_нұсқа_математика.pdf` (10 заданий, ключ: B A B C A C B ACE BC B). Это тренировочные задания, не официальный вариант ЕНТ.

## 6. Как устроена защита

- **Код класса**: 5 символов, 3 буквы + 2 цифры (`KUN47`). Без похожих символов `0/O`, `1/I/L`.
  Кириллица, набранная по ошибке (`КUN47`), понимается правильно. Ручной код: 5–6 латинских букв и цифр.
- После ввода кода сервер ставит куку `cls` (HttpOnly, на 1 год), а телефон дополнительно хранит код в `localStorage`.
  При смене кода класса старый код перестаёт работать у всех.
- **Каждый файл** (`/f/<id>`) проверяется на сервере: материал должен быть общим или принадлежать классу из куки.
  Чужой файл по прямой ссылке получает `403`.
- **Подбор кода и PIN**: неверные попытки считаются по IP за 15 минут (20 для кодов, 5 для PIN). После блокировки отклоняется даже верный код.
  Лимит для кодов намеренно мягкий: в школе много учеников выходят в интернет с одного IP.
- **Учитель**: подписанная HMAC кука на 30 дней (смена PIN завершает все сессии), `SameSite=Strict`,
  изменения только с заголовком `X-Req` (защита от CSRF), PIN сравнивается за постоянное время.
- Принимаются только PDF/Word/PowerPoint до 20 МБ; тип файла определяет сервер по расширению.
  Ссылки только `http(s)://`. На страницах строгий Content-Security-Policy.
- Имена файлов на казахском: `Content-Disposition` с `filename*=UTF-8''…` (RFC 6266) и латинской транслитерацией для старых браузеров.

## 7. Проверка

```bash
npm test
```

Автотесты запускают настоящий сервер и проверяют:
- ученик 7Ә **не видит** материалы 8Ғ и **не скачивает** PDF 8Ғ по прямой ссылке (`403`), даже без куки или с поддельной;
- ученик 8Ғ открывает свой PDF, байты совпадают с оригиналом;
- **неверный PIN** не пускает учителя, поддельная кука учителя не работает;
- **казахские имена** (`Теңдеулер_үй_тапсырмасы_№3.docx`, `Бақылау жұмысы №2 (Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І).docx`) сохраняются и скачиваются правильно;
- файл больше 20 МБ, `.exe` и ссылка `javascript:` отклоняются; запрос без `X-Req` отклоняется;
- после смены кода класса старый код не работает; повторяющийся код не принимается;
- подбор кода и PIN блокируется;
- сайт «в интернете» без `ADMIN_PIN`: страница учителя закрыта.

Проверка на Postgres (кроме режима `data/`): `TEST_DATABASE_URL=postgresql://… npm test`. Тест **удаляет таблицы** в этой базе, поэтому используйте отдельную пустую базу, не рабочую.

## Структура

```
src/server.js         запуск, перенос файлов, пример
src/app.js            маршруты и проверки доступа
src/auth.js           PIN и сессия учителя
src/ratelimit.js      ограничение неверных попыток
src/db/pg.js          Postgres (Neon)
src/db/json.js        локальная папка data/
src/storage/          хранилища файлов: db (bytea), local, b2 (S3 SigV4)
public/               страницы ученика (index), учителя (admin), стили, шрифт
scripts/seed.js       пример: 3 класса, 5 материалов
scripts/migrate-files.js  ручной перенос файлов
seed/                 файлы примера (PDF, Word, PowerPoint)
test/                 автотесты
```
